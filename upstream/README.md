# Imported Sources

このディレクトリは元プロジェクトのソース・スクリプト・仕様のスナップショットです。
出典とファイルごとのSHA-256は `import_manifest.json` に記録します。
コピー時点の未コミットファイルも含むため、Gitコミットだけで内容を特定しないでください。

`low_cost_robot/scripts/teleoperate_real.py`、`bimanual_teleop.py`、`teleoperate_sim.py` は
実機通信とトルク変更を含みます。`Robot` のコンストラクタもトルクを書き換えます。
現在の情報読み取り専用の作業では実行しません。名前にsimがあっても実機非接続とは限りません。

コピーしたPythonモジュールをメインのuv環境へインストールしていません。
CAD・MuJoCo・カメラ用の依存関係は各コピー先の `pyproject.toml` / `uv.lock` を参照します。
生成物、仮想環境、バイナリCAD、メッシュ、画像等はコピー対象外です。
元の相対パスや外部CAD入力を必要とするスクリプトは、そのまま単独実行できるとは限りません。
今回検証した実機コマンドはメイン環境の `arm-status` のみです。

コピー手順は `../scripts/import_upstream.py` にあります。既存のコピーと内容が異なる場合は
上書きせず終了します。更新時は差分を確認してから新しいスナップショットを用意してください。
